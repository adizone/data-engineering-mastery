# Data Engineering Mastery

> A structured journey from Data Engineer to Senior Data Engineer.

## Purpose

This repository documents my learning, projects, experiments, and system design work while mastering modern Data Engineering.

The goal is to develop a deep understanding of:

- Computer Science Fundamentals
- Distributed Systems
- Data Processing
- Data Warehousing
- Cloud Data Platforms
- Data Lakehouse Architectures
- Streaming Systems
- Infrastructure & DevOps
- AI Data Engineering
- Large Scale System Design

This repository focuses not only on **how** technologies work but also on **why** they exist and the trade-offs behind engineering decisions.
